MISE À JOUR CIBLÉE DU BLOGUE

Nouveaux thèmes :
- Langage de programmation
- Visualisation de données
- Analyse de données

Sujets :
- R
- Power BI
- Power Query

Chaque thème peut être croisé avec chaque sujet.

Le workflow n'accepte désormais que des sources Data / BI / Data Science spécialisées.
Il préfère afficher moins d'articles plutôt que des contenus hors sujet.

À remplacer sur GitHub :
- blog.js
- blog-data.json
- update_blog.py

Après remplacement :
GitHub > Actions > Update Blog Articles > Run workflow.
