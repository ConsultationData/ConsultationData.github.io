CONSULTATION DATA — FICHIERS À DÉPOSER SUR GITHUB

Dépose directement ces fichiers à la racine du dépôt ConsultationData.github.io :

- index.html
- styles.css
- script.js
- realisations_futuristes.png
- realisations_futuristes_en.png

Étapes :
1. Ouvre ton dépôt GitHub.
2. Clique sur Add file → Upload files.
3. Dépose ces 5 fichiers.
4. Remplace les anciens fichiers si GitHub te le demande.
5. Clique sur Commit changes.
6. Attends 1 à 5 minutes.
7. Recharge https://consultationdata.github.io
8. Si nécessaire, fais Ctrl + F5.
